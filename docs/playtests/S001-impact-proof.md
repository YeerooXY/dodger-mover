# S001: Impact Proof playtest

Allow five minutes. Extract the Windows build and run `DodgerMover.exe`; Unity is not needed.

Move into the orange training unit, experiment with the attacks, and restart at least once. The raised platform is part of the room. There is no score, timer, or penalty for experimenting.

| Action | Keyboard | Xbox / PlayStation-style pad |
| --- | --- | --- |
| Move | A/D or left/right arrows | Left stick or D-pad |
| Jump | Space, W, or up arrow | A / Cross |
| Light | J or X | X / Square |
| Heavy | K or C | Y / Triangle |
| Launcher | L or V | B / Circle |
| Restart room | R or the on-screen button | Start / Options |
| Diagnostics | F1 | Select / Share |
| Exit | Escape | Close the game window |

Please answer after playing:

1. Which action felt best?
2. What felt slow, weak, confusing, or accidental?
3. Did you voluntarily try a different sequence after understanding the controls?
4. If you could change only one thing, what would it be?

The art and audio are authored placeholders. This slice tests movement and impact; your feedback decides the next slice. Automated verification and remaining infrastructure gates are recorded in [the slice document](../slices/S001-impact-proof.md).
